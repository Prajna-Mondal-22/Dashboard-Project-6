# 🏥 Hospital Data Analysis Dashboard – Power BI

## 📌 Project Overview

The **Hospital Data Analysis Dashboard** is an interactive Power BI project designed to analyze hospital-related data and generate meaningful insights into patient demographics, medical conditions, hospital costs, recovery rates, patient satisfaction, and readmission patterns.

The dashboard transforms healthcare data into visual reports that help understand hospital performance and patient-related trends.

## 🎯 Project Objectives

- Analyze total patient and recovery statistics.
- Understand patient distribution by gender.
- Explore hospital costs across medical conditions and procedures.
- Evaluate patient satisfaction levels.
- Analyze patient age and length of hospital stay.
- Explore patient outcomes and readmission patterns.
- Build an interactive dashboard for healthcare data exploration.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and visualization.
- **Power Query** – Data transformation and preparation.
- **DAX (Data Analysis Expressions)** – KPI calculations and measures.
- **Data Visualization** – Interactive charts, cards, and slicers.

## 📊 Dashboard Features

### 1. KPI Cards
- Total Patients
- Total Hospital Cost
- Recovered Patients
- Average Patient Age

### 2. Patient Demographics
- Gender-wise patient distribution.
- Patient count by gender.

### 3. Medical Condition Analysis
- Patient age distribution across medical conditions.
- Average hospital cost by medical condition.
- Length of stay across different medical conditions.

### 4. Hospital Cost Analysis
- Procedure-wise hospital cost comparison.
- Identification of procedures associated with higher hospital costs.

### 5. Patient Satisfaction Analysis
- Patient distribution by satisfaction level.

### 6. Interactive Filters
- Gender
- Satisfaction
- Readmission
- Patient Outcome

## 📈 Key Analytical Areas

The dashboard focuses on understanding:
- Patient demographics and healthcare distribution.
- Cost variations across medical procedures.
- Differences in hospital stay duration.
- Patient satisfaction patterns.
- Recovery and readmission-related information.
